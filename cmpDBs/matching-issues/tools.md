# Tools that compare the data of PostgreSQL tables

This list holds the tools that can connect to two PostgreSQL databases and say whether the data of a table is the same on both. A tool is here when it can be a subject of the test in `README.md`.

The descriptions come from the documentation of each tool, read on 2026-11-13. Every link was opened on that day, except where a note says otherwise. No tool of the list was run on this data set yet. "Last change" is the date of the last push to the repository on that day.

## Open source: tools that report the rows

These tools name the rows that differ, so their result can be compared with the expected rows of the register.

| Tool | What it is | What a test must know | Links |
|---|---|---|---|
| ACE (pgEdge) | Active Consistency Engine. Written in Go, PostgreSQL License. `table-diff` compares block hashes between the nodes of a cluster; `mtree` keeps a Merkle tree for repeated comparisons; `table-repair` changes the data of a node; `schema-diff` and `repset-diff` cover groups of tables. Last change: 2026-11-13. | Made for pgEdge clusters with Spock. Needs a cluster description (`pg_service.conf`) and `ace.yaml`. Many expected results of the register name its commands and options. | [GitHub](https://github.com/pgEdge/ace) |
| pg_comparator | A Perl script. It builds a table of checksums and a tree of summary tables on each side, and compares the trees, so only a small part of the data goes over the network. It can also synchronize the second table. Works with PostgreSQL, MySQL and SQLite. Version 2.3.2; last change of the repository: 2020-11-03. Debian has it as the package `postgresql-comparator`. | One table for each run; the key and the columns are a part of the connection URL. It creates its tables on both sides. By default a NULL is replaced by the text `NULL` (`--null=text`), and the search stops when more than 10% of the rows differ (`--max-ratio=0.1`). The manual says that it is really tested only with integer and text types. | [Home page and manual](https://www.cri.minesparis.psl.eu/~coelho/sw/pg_comparator), [GitHub](https://github.com/zx80/pg_comparator) |
| pgCompare (Crunchy Data) | Written in Java, Apache 2.0. It stores a hash of the key and a hash of the other columns of each row in a repository database and compares them there. `compare` finds the rows, `check` reads them again. Works across platforms (Oracle, DB2, MySQL, MariaDB, SQL Server, Snowflake, PostgreSQL). HTML report; generation of fix SQL is a preview. Version 0.6.0. Last change: 2026-09-22. | Needs Java 21 and one more PostgreSQL database for the repository. One schema of the source is mapped to one schema of the target, so the main set needs one run for each schema. Tables are registered by `discover`. Documented limits: timestamps are compared only to the second, `bytea` is not supported, low precision numbers are cast with a scale of 3. | [GitHub](https://github.com/CrunchyData/pgCompare) |
| reladiff | Written in Python, MIT license. A fork of data-diff. It splits the key range into segments, compares a hash of each segment, and reads only the segments that differ. Works across more than ten database systems; two tables of one database are compared with a join. Output as text or JSON. Last change: 2025-08-18. | One table for each run. The key is given with `-k`; every other column that must be compared is given with `-c`. | [GitHub](https://github.com/erezsh/reladiff), [documentation](https://reladiff.readthedocs.io/en/latest/) |
| data-diff (Datafold) | The project that reladiff comes from. The repository is an archive since 2024-05-17 and is not developed any more. | Only for a comparison with reladiff. | [GitHub](https://github.com/datafold/data-diff) |
| SQL Workbench/J, command `WbDataDiff` | A free SQL client in Java with a batch mode. `WbDataDiff` reads every row of the reference and of the target table through JDBC and writes SQL scripts (`UPDATE`, `INSERT` and, with `-includeDelete=true`, `DELETE`) that make the target equal to the reference. | It reports the differences only as these scripts (or XML). Every table needs a primary key: the command stops at a table without one, or takes a key from `-alternateKey`. Columns can be left out with `-ignoreColumns`. | [Home page](https://www.sql-workbench.eu/) (see the note under the table) |
| Data Validation Tool, DVT (Google) | A Python command line tool on the Ibis framework, Apache 2.0. Column validation compares aggregates (count, sum, min, max and others); row validation joins the rows by a key and compares a hash or the values of chosen columns; there is also a schema validation and a validation of custom queries. PostgreSQL and AlloyDB are among 16 connection types. Last change: 2026-11-13. | Only the row validation finds single rows; it needs `--primary-keys` and one of `--hash`, `--concat`, `--comparison-fields`. The manual says that `--hash` casts each value to a string and applies `ifnull`, `rtrim` and `upper` before the hash. `--use-random-row` checks a sample of rows. | [GitHub](https://github.com/GoogleCloudPlatform/professional-services-data-validator) |

Note on SQL Workbench/J: on 2026-11-13 its site (`sql-workbench.eu`, older name `sql-workbench.net`) refused requests of a program, so the link was not opened and the current build number was not checked. The text above comes from the chapter "Comparing databases" of its manual, read from a copy of the manual of an older build.

## Open source: tools that give a verdict for a table

These tools say that a table (or a range of its rows) differs, but they do not name the rows. Only the verdict can be judged.

| Tool | What it is | What a test must know | Links |
|---|---|---|---|
| pgcopydb compare | A part of pgcopydb, a tool that copies a database (written in C). `compare data` computes the row count and one checksum for each table on both sides; `compare schema` compares the lists of tables, indexes, constraints and sequences. Last change: 2026-11-03. | Compares all tables of the database in one run. The checksum is the sum of `hashtext()` of the text of each row, read `FROM ONLY` the table. The exit code is not zero when a table differs; `--json` gives the result as JSON. | [Manual](https://pgcopydb.readthedocs.io/en/latest/ref/pgcopydb_compare.html), [GitHub](https://github.com/dimitri/pgcopydb) |
| pgverify | A Go module and command line tool, MIT license. It compares two or more databases that speak the PostgreSQL protocol (PostgreSQL 10 or newer, CockroachDB). Test modes: `full` (an MD5 hash of all rows of a table), `bookend` (the first and the last rows), `sparse` (about one row of each N), `rowcount`. Last change: 2026-11-10. | Only the `full` mode reads every row. A `jsonb` value is compared by the length of its text. The repository of Udacity is a fork of the first link. | [GitHub](https://github.com/cjfinnell/pgverify), [fork of Udacity](https://github.com/udacity/pgverify) |
| pgdatadiff | A small Python tool, MIT license. It compares the row count of each table and then MD5 sums of chunks of rows that the server computes; it also compares sequences. It reports a range of rows, not the rows. The repository is an archive (last change: 2024-06-27). | The MD5 sums use the values cast to `varchar`. The chunk size is an option (`--chunk-size`, 10000 by default). | [GitHub](https://github.com/dmarkey/pgdatadiff) |
| rust-pgdatadiff | A new version of pgdatadiff in Rust, MIT license. It works in parallel, knows schemas, and compares tables and sequences. It is a command line client and a library. Last change: 2026-11-02. | One schema for each run (`--schema-name`); tables can be included or excluded by name. | [GitHub](https://github.com/pavlospt/rust-pgdatadiff) |

## Commercial tools

| Tool | What it is | What a test must know | Links |
|---|---|---|---|
| LiveCompare (EDB) | Compares any number of databases, writes a report and a list of differences, and generates DML scripts that fix them. It splits a large table into rounds by the key and runs them in parallel; found differences can be checked again later. It knows native logical replication, pglogical and EDB Postgres Distributed, and can compare Oracle with PostgreSQL. Version 4. | Needs one more database for its output and its cache. A column of the key that cannot be sorted is cast to text. | [Documentation](https://www.enterprisedb.com/docs/livecompare/latest/) |
| dbForge Data Compare for PostgreSQL (Devart) | A desktop program with a command line interface. It compares tables, views and the results of queries, shows the differences in a grid, writes reports (CSV, Excel, HTML) and generates synchronization scripts. PostgreSQL 8.4 to 18. | Its comparison options include rounding of float values and ignoring of case and of trailing spaces: record which options are on. | [Product page](https://www.devart.com/dbforge/postgresql/datacompare/) |

| Data compare of DBeaver | A function of the DBeaver desktop client. It compares two tables, a table with a query, or two queries, also between different database systems; shows the differences in a viewer; exports them as an SQL script or an HTML table. Only in the Enterprise, Ultimate and Team editions. | A wizard, or a saved task. The key is the unique key of the table or columns chosen by hand. Two settings stop a comparison early: a limit of compared rows and a limit of different rows. | [Documentation](https://dbeaver.com/docs/dbeaver/25.3/Data-compare/) |
| EMS Data Comparer for PostgreSQL | A desktop program with a wizard and a command line utility. It compares and synchronizes the data of several tables in one run. A trial of 14 days. | The product page gives no version and no list of supported server versions. | [Product page](https://www.sqlmanager.net/products/postgresql/datacomparer) |
| Datanamic DataDiff | A desktop program for nine database systems. It compares chosen tables and fields, with a key that it finds or that the user defines, and synchronizes directly or by a script. Version 9.0.1. | The page lists PostgreSQL 7 to 16, not 17 or 18. The command line utility and a comparison between different database systems need the Professional edition. Its options include: ignore spaces, trim strings, match NULL to an empty string, ignore case. Record which are on. | [Product page](https://www.datanamic.com/datadiff/) |

## Not a subject of this test

- **MOLT Verify (Cockroach Labs)** compares the rows of a source PostgreSQL database (12 to 16) with a target, but the target must be CockroachDB. It cannot compare two PostgreSQL databases. [Documentation](https://www.cockroachlabs.com/docs/molt/molt-verify).
- **Tools that compare only the schema**, for example the Schema Diff of pgAdmin, Atlas, Liquibase and Redgate pgCompare. The last one has the same name as the tool of Crunchy Data, but it is another product.
- **A plain SQL comparison** through `postgres_fdw` or `dblink`, or `expected.py` of this repository, is not a tool under test. It is a way to compute the expected result and to check the data.
